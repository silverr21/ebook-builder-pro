# eBook Builder Pro - Laravel AI-Powered eBook Creation Platform

🚀 **Enterprise SaaS Platform** pro tvorbu, správu, publikování a prodej e-knih s umělou inteligencí.

## ✨ Klíčové Vlastnosti

### 📝 Editor
- Rich Text Editor s Quill
- Autosave & Cloud Backup
- Version History
- Offline režim
- Dark/Light Mode

### 🤖 AI Writer
- Generování titulů a kapitol
- Rozšíření/zkrácení textu
- Přepis v různých stylech
- Pokračování psaní
- Kontrola gramatiky
- SEO optimalizace

### 🎨 Design System
- 5+ šablón designu
- Přizpůsobitelná typografie
- Responzivní layout
- Live preview

### 📤 Export
- PDF, EPUB, MOBI, DOCX, Markdown, HTML

### 👥 10 Rolí
Super Admin, Admin, Editor, Autor, Korektor, Grafik, Překladatel, Čitatel, Předplatitel, Hosť

## 🔧 Technologie

- **PHP 8.4+** / Laravel 13
- **MySQL 8.0+** / Redis
- **Tailwind CSS** / Alpine.js
- **Quill Editor** / Livewire
- **OpenAI API** pro AI
- **Docker Ready** / CI-CD

## 📦 Instalace

```bash
composer install
npm install
php artisan app:install
npm run build
php artisan serve
```

## 📖 Dokumentace

- API: `/routes/api.php`
- Services: `/app/Services/`
- Controllers: `/app/Http/Controllers/`
- Models: `/app/Models/`

## 🚀 Deployment

```bash
# Docker
docker-compose up -d

# Traditional
composer install --no-dev
npm run build
php artisan migrate --force
```
